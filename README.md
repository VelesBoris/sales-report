# daily_by_sku

Скрипт `calc.py` читает выгрузку заказов `sales.csv` и строит `output/daily_by_sku.csv`: по каждой паре «sku — день» число уникальных заказов (`orders`, включая cancelled) и выручку по delivered (`revenue`).

## Как запустить

**Зависимости:** не нужны. Python 3.8+, только стандартная библиотека.

1. Клонируйте репозиторий и перейдите в его папку:
   ```
   git clone https://github.com/VelesBoris/sales-report.git
   cd <папка репозитория>
   ```
2.  Положите в папку `data` выгрузку как `data/sales.csv`. Формат: CSV, UTF-8, запятая, колонки `order_id, order_date, sku, quantity, price, status`.
3. Запустите из папки репозитория:
   ```
   python calc.py
   ```
   или двойным кликом по `run.bat` (Windows). Другой путь к файлу: `python calc.py путь\к\файлу.csv`.

**Результат:** `output/daily_by_sku.csv` (колонки `sku, order_date, orders, revenue`, сортировка по sku, затем по дате). Контрольные цифры печатаются в консоль.


## Как проверяли расчёт

**Контрольные цифры скрипта**:
- прочитано строк = учтено + дубли + неизвестные статусы + ошибки данных (скрипт печатает `True`/`False`);
- сумма `orders` = число уникальных заказов (`True`/`False`);
- на нашей выгрузке: прочитано 13 858, дублей 60, уникальных заказов 13 798, строк в результате 631, Σ revenue 10276540.

**Ручная сверка** (независимо от кода, в Excel):
- по исходному файлу вручную посчитано: Σ revenue по delivered после удаления дублей = 10276540;
- для выборки пар «sku — день» (<сколько пар, какие, в том числе с revenue = 0>) `orders` и `revenue` пересчитаны фильтром? с условным форматированием при дублировании ордеров;
- результат: цифры совпали с `output/daily_by_sku.csv`.
